# Gender Stereotypes Project - Study 2

## Overview

This repository contains data management, analysis scripts, documentation, and project materials for **Study 2 of the Gender Stereotypes Project**.

The primary goal of Study 2 is to determine whether **five vignettes generated from participants' open-ended responses provide sufficient information for observers to classify targets into gender categories and gender-role groups**.

This repository currently serves as the team's collaborative analysis environment and may later serve as an open science repository for sharing reproducible materials, documentation, and analysis code.

## Repository Purpose

This repository is intended to:

- Store analysis code and documentation.
- Maintain a reproducible workflow using GitHub and RStudio.
- Facilitate collaboration among project team members.
- Track project changes through version control.
- Store analysis outputs and supporting materials.
- Potentially serve as a future open science repository.

---

## Research Question

Can a small set of vignettes generated from open-ended participant responses provide sufficient information for observers to accurately categorize targets according to:

- Gender categories (e.g., man, woman)
- Gender-role categories (e.g., masculine, feminine)

### Folder Descriptions

- Never modify raw datasets directly.
- Preserve an unchanged copy of the original data.

#### data/processed/

Cleaned and restructured datasets used for analyses.

#### output/
